# Primeiro uso

Cria a pasta pessoal: o lugar onde ficam personalização, ideias, planos e tarefas da pessoa, separado dos arquivos do plugin. Atualizar o plugin não apaga nada dessa pasta.

## Passos

1. **Confirmar.** Dizer em poucas palavras que a pasta da conversa (informada no aviso do início) vai virar a pasta pessoal, o que será criado nela e que atualizações do plugin não mexem ali. Criar só com o sim da pessoa.
2. **Conferir conflitos.** Se a pasta já tiver `AGENTS.md`, `CLAUDE.md` ou `TAREFAS.md`, não sobrescrever: mostrar o que existe e combinar com a pessoa antes de seguir. Se a pasta já tiver uma lista de tarefas com outro nome (por exemplo, `task.md`), não criar `TAREFAS.md` sem combinar: perguntar à pessoa qual lista usar e, se ela mantiver a própria, anotar o nome na seção "Fontes" do `AGENTS.md` criado.
3. **Criar** a partir de [modelo-pasta-pessoal](../../../modelo-pasta-pessoal/), copiando o conteúdo sem mudanças:
   - `AGENTS-pessoal.md` → `AGENTS.md` (a primeira linha identifica a pasta pessoal; não remover);
   - `CLAUDE-pessoal.md` → `CLAUDE.md`;
   - `TAREFAS.md` → `TAREFAS.md`, salvo se a pessoa mantiver a lista própria (passo 2);
   - pastas vazias `ideias/` e `planos/`.
4. **Conferir** que os arquivos existem e correspondem aos modelos. Se algo falhar, informar o que falta.
5. **Encerrar** dizendo onde a pasta ficou e o único próximo passo: organizar a ideia, pela etapa atual da lista de tarefas. Não iniciar essa etapa sem pedido.
